Installation and setup
Clone the Repository - git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
Create a virtual environment in project folder -python -m venv venv
Activate the virtual environmet
Mac/Linux -source venv/bin/activate
Windows -venv\Scripts\activate
Install dependencies -pip install flask flask-cors
Run the application -python app.py
The application will run locally at -http://127.0.0.1:5000
